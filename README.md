# 🌿 Plant Care - Frontend

Plant Care is a modern, responsive plant management platform where users can explore plants, add their own plants, track plant health and watering information, and manage their personal collection. The application provides a clean and user-friendly interface with secure authentication and smooth interactions.

Fully Responsive for Mobile, Tablet & Desktop

Client site: [Plant Care Client](https://github.com/Mezbahul-241-15-929/plantcare)

Server site: [Plant Care Server](https://github.com/Mezbahul-241-15-929/plantcare-server)

Live site: [Plant Care Live](https://plantcareclient.netlify.app/)

---

## 📖 Project Description

Plant Care helps plant lovers organize and maintain their plants efficiently. Users can browse all available plants, view detailed plant information, add new plants, update plant details, and manage the plants they have added.

The project focuses on responsive UI design, secure Firebase authentication, helpful plant information, and a smooth React-based user experience.

---

## ✨ Features

### 🔐 Authentication System
- User registration and login
- Firebase email and password authentication
- Google Sign-In
- Protected routes for plant management
- Persistent user sessions
- User profile image and logout functionality

### 🌱 Plant Management
- Browse all plants
- View detailed plant information
- Add new plants to the collection
- Update plant details
- Delete personally added plants
- Organize plants by category
- Track care level, health status, and last watered date

### 👤 User Plant Collection
- View plants added by the logged-in user
- Manage personal plant records
- Update or remove owned plants
- Access plant care details from the dashboard

### 🎨 Modern UI
- Responsive design for mobile, tablet, and desktop
- Hero carousel section
- New plants showcase
- Plant care information sections
- Mobile-friendly navigation menu
- Clean green-themed interface
- Confirmation and feedback alerts with SweetAlert2

### ⚡ Performance
- Fast React single-page application
- Dynamic data loading with React Router loaders
- Reusable component structure
- Responsive Tailwind CSS utilities
- REST API integration for plant data
